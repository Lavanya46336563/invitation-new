# Saravanan & Ragasudha – Wedding Invitation (React + Vite)

## Add your files to /public (same names as the original site)
hero.jpg, couple2.jpg, gallery1.jpg … gallery10.jpg, eventbg-wedding.jpg, eventbg-reception.jpg, finalbg.jpg, music.mp3

## Run locally
npm install
npm run dev

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. vercel.com → Add New → Project → import the repo (Framework: Vite, build: `npm run build`, output: `dist`).
3. Deploy. Or: `npx vercel --prod`
